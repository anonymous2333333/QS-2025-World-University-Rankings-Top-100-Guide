# 实现说明

## 设计取舍

保留原项目轻量静态站点的使用方式，以“探索一所学校”为主要任务。主色 #245BD6、背景 #F5F8FC、正文 #172B4D、分隔线 #DFE7F2、辅助文字 #5D6F89、深色背景 #111B2E；沿用原项目的蓝白视觉方向，去掉无来源的诺贝尔奖总数与持续渐变动画。

主视觉使用现有世界地图，传递真实的院校地域分布；不依赖装饰图片或远程字体。字体以本机 Avenir / Segoe UI 和中文系统字体回退，离线环境可直接阅读。标题集中表达探索主题，工具区左侧筛选、右侧结果，手机端筛选自动移到列表上方。排名数字用于真实名次，学校身份单独编码。

参考的前端制作与审查资料：

- [Anthropic Frontend Design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：主题相关视觉、排版层级、减少无意义装饰与动态效果。
- [Vercel Web Design Guidelines](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md) 与 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)：语义结构、标签、可见焦点、键盘、URL 状态、空结果和错误反馈。

## 数据、状态与安全

`js/core.js` 使用 UMD，同时供普通脚本和 Node 测试加载。纯函数与 DOM 操作分开，不引入前端打包依赖。初始数据最大等待 5 秒，超时、HTTP 错误、错误 JSON、缺少记录或字段错误时使用内置资料。文件协议优先使用内置数据以避免 CORS；两个通道均无效时提供重试。地图独立加载，不阻塞院校阅读；使用固定 viewBox 自适应，避免反复测量和重绘事件。

原数据的行序号与名次分离。修正表以行序号定位，收藏、详情、对比和链接只使用 `id`。生成器按学校名称匹配章节，最长名称优先，避免“哥伦比亚大学”误匹配“不列颠哥伦比亚大学”；输入存在重复章节或缺项时不覆盖现有数据。在线与离线数据由同一份序列化输出。

筛选条件、当前页、详情编号和对比编号写入 URL；显式 `compare=` 可清空旧名单，无该参数时保留浏览器的对比记录。URL 中未知编号、枚举和值会被清理。收藏仅保存本机，不自动传送到服务器；分享收藏筛选时，接收者仍使用自己的收藏。CSV 输出所有匹配记录，和当前页是否展示无关。

存储采用带版本的键 `qs-explorer:v2`，读写均捕获异常，并清理失效或重复编号。损坏缓存或浏览器禁止持久化时，页面仍可工作。多个标签页通过 `storage` 事件同步收藏、对比和主题。

所有来自数据和 URL 的动态文本统一进行 HTML 转义；不把原始 Markdown 当 HTML 执行。CSV 对以 =、+、-、@ 开头（包括前导空白）的单元格增加防护前缀。外链窗口使用 noopener，运行资源均随项目提供。

## 维护边界

本轮修复名次和生成器，不将原资料的全部历史、学科描述或参访建议视为已核验事实。原 Markdown 保留以便追溯；详情中可能保留旧叙述，结构化名次字段与来源说明是对照口径。2025 年后的学校合并、更名和参访政策需要额外来源，不能直接改写成最新信息。

没有新增账户、后端、远程分析、费用或录取概率等未经数据支持的功能。后续如引入多年度排名，应以稳定学校实体编号关联年份，不能按名次关联；如引入申请信息，应另建可核验来源、日期与更新周期字段。
