## 复现故障页面

```bash
npm run build
npm run qa:fixtures
python3 -m http.server 3000 --directory dist
```

打开 `/qa/fallback/`、`/qa/missing-map/`、`/qa/missing-data/` 与 `/qa/viewport-320/`、`/qa/viewport-390/`、`/qa/viewport-768/`。这些页面只存在于生成目录。重新执行常规 `build` 会清除它们，生产导出不包含故障夹具。

## 已知内容边界

只修正可追溯的 2025 名次、一个英文院校名称和解析缺陷；原资料中的学科断言、历史表述与参访政策未全部独立核实。界面、详情和 README 均说明资料年份与适用范围。学科筛选来自亮点关键词，不能替代课程目录或学科排名。

## 交付与应用

首次打包时尚未推送；取得原仓库写权限后，按用户要求将升级版更新至原仓库。GitHub 更新采用普通向前提交，保留既有历史。源码压缩包可直接打开；压缩包根目录的 `UPGRADE.patch` 为基于上述提交的 Git 补丁：在原仓库干净工作区运行 `git apply --check UPGRADE.patch`，确认后 `git apply UPGRADE.patch`。已存在其他改动时，应先在独立分支检查冲突。
