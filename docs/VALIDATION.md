## 故障复现

```bash
npm run build
npm run qa:fixtures
python3 -m http.server 3000 --directory dist
```

访问 `/qa/fallback/`、`/qa/missing-map/`、`/qa/missing-data/`、`/qa/missing-photo/`、`/qa/missing-detail/` 和 `/qa/viewport-{320,390,768}/`。夹具仅存在于生成目录；重新执行常规 build 清除它们，生产导出不含故障路由。
